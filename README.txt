READ ALOUD  (version 2 - natural voices)
=======================================
Highlight text in any program and press Ctrl+Alt+R to hear it read out loud.

INSTALL
1. Right-click the zip file > Properties. If there is an "Unblock" tick box
   at the bottom, tick it and click OK. Then right-click > Extract All.
2. Open the extracted folder and double-click Install.cmd.
   (If Windows shows "Windows protected your PC", click "More info" > "Run anyway".)
3. A "Read Aloud" shortcut is added to your Desktop and the app starts.
   To have it start automatically, right-click the speaker icon in the
   system tray and tick "Run at startup".

Installing again over an older version is fine - it closes the old one first.

VOICES
Right-click the speaker icon > Voice.
- Natural voices (Ryan, Sonia, Libby, Andrew, Emma...) are Microsoft's
  neural voices - the same ones Edge uses for "Read aloud". They sound
  very human but need an internet connection.
- Windows voices (George, Hazel, David...) work offline.
If a natural voice can't be reached, it automatically carries on with a
Windows voice.

SHORTCUT KEYS
  Ctrl+Alt+R   Read highlighted text / Stop
  Ctrl+Alt+P   Pause / Resume
  Ctrl+Alt+=   Speak faster
  Ctrl+Alt+-   Speak slower
  Ctrl+Alt+V   Next voice

If another program already uses Ctrl+Alt+R, Read Aloud picks a free
shortcut automatically and tells you which. You can also choose one from
the tray menu: "Change read shortcut".

Requires Windows 10 or 11. Nothing else needs to be installed.
